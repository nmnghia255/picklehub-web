HƯỚNG DẪN CÀI ĐẶT

1. Mục đích

Tài liệu này hướng dẫn cài đặt môi trường tối thiểu để chạy và kiểm thử nhanh dự án PickleHub Web từ mã nguồn đã có sẵn.

2. Công cụ cần cài

- Node.js 20 LTS hoặc mới hơn (khuyến nghị 20 hoặc từ 22 trở lên).
- pnpm phiên bản 9 trở lên, dùng làm trình quản lý gói.
- Visual Studio Code hoặc trình soạn thảo tương đương (khuyến nghị).
- Trình duyệt web hiện đại như Chrome, Edge hoặc Firefox.

3. Chuẩn bị mã nguồn

Giải nén hoặc mở thư mục mã nguồn của dự án.

Mở terminal tại thư mục gốc của dự án, nơi có các file:
- package.json
- next.config.ts
- env.example
- thư mục src

4. Cài đặt dependency

Nếu chưa có pnpm, cài đặt bằng lệnh:

npm install -g pnpm

Tại thư mục gốc dự án, chạy:

pnpm install

5. Cấu hình môi trường

Tạo file .env.local từ file mẫu.

Nếu dùng Windows:

copy env.example .env.local

Nếu dùng Linux/macOS:

cp env.example .env.local

Mở file .env.local và điền các giá trị:
- APP_URL: địa chỉ ứng dụng, mặc định http://localhost:3000
- NEXT_PUBLIC_API_GATEWAY_URL: địa chỉ API backend, mặc định http://localhost:8000
- SESSION_SECRET: chuỗi bí mật, tối thiểu 32 ký tự
- NEXT_PUBLIC_GOOGLE_CLIENT_ID: Client ID lấy từ Google Cloud Console
- NEXT_PUBLIC_FACEBOOK_APP_ID: App ID lấy từ Facebook Developers

Ứng dụng cần backend API tại NEXT_PUBLIC_API_GATEWAY_URL hoạt động để đăng nhập và sử dụng đầy đủ chức năng.

6. Kiểm tra môi trường

Kiểm tra phiên bản đã cài đặt:

node --version
pnpm --version

Nếu hai lệnh trên trả về phiên bản, môi trường đã sẵn sàng để chạy dự án. Xem cách biên dịch và chạy trong file HuongDanSuDung.txt.
